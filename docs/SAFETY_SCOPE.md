# 安全验证范围与下一阶段路线

## 本仓库能验证什么

| 项目 | 方法 | 结论类型 |
|---|---|---|
| 末端位置可达性 | 解析逆运动学 | 几何可达 / 不可达 |
| 位置奇异性 | 3×4 位置雅可比奇异值 | 阈值筛查 |
| 关节限位 | 数学角与限位逐项比较 | 通过 / 不通过 |
| 简化路径 | 关节空间线性插值离散采样 | 采样点通过 / 不通过 |
| 底座与地面 | 点和简化禁入区 | 粗略筛查 |
| 治疗空间 | 规则网格逐点逆解 | 近似覆盖率 |

## 本仓库不能验证什么

- 电机、减速器、轴承、连杆在负载下的强度与寿命
- 速度、加速度、jerk、惯量、重力、摩擦和反驱特性
- 连杆之间、机械臂与人体或环境之间的精确碰撞
- 末端接触力、皮肤压强、夹伤、冲击和热风险
- 编码器漂移、总线超时、计算卡死、断电和单点故障
- 控制回路稳定性、柔顺控制或阻抗控制的稳定裕度
- 医疗有效性、临床风险或法规符合性

## 建议的下一阶段

1. **导入真实几何**：建立 URDF/SDF，加入连杆碰撞体、质量、惯量和真实关节轴。
2. **动力学仿真**：在 Isaac Sim、MuJoCo 或 Gazebo 中验证重力补偿、速度/加速度和制动距离。
3. **路径规划**：用连续碰撞检测和带约束的轨迹规划替代关节线性插值。
4. **接触安全**：增加六维力/扭矩传感器、机械限力结构、软件力限制和独立硬件急停。
5. **故障分析**：针对编码器、驱动器、通信、电源和计算平台做 FMEA/FTA，并设计独立安全通道。
6. **标准与测试**：由合格团队依据目标产品类别确认适用标准、风险管理、验证和临床要求。

## 对“任意一点都安全可达”的正确表述

建议将需求写成：

> 在预先定义的封闭治疗工作空间 W 内，每个离散验证点至少存在一个满足关节限位余量、位置雅可比阈值和简化禁入约束的逆解；由当前安全初始位形到该逆解存在一条经过连续碰撞和动力学验证的轨迹。

本仓库只覆盖这句话中“离散验证点、逆解、关节限位余量、位置雅可比阈值和简化禁入约束”的部分。
