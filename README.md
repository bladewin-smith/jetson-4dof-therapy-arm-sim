# Jetson P1+4R Therapy Arm Simulator

一个面向 **Jetson Orin Nano** 的、完全离线的 `P1 + 4R` 连杆机械臂正逆运动学可行性验证仓库。它用于在制造样机前快速回答三个问题：

1. 给定连杆长度和关节限位，末端能否到达目标点？
2. 到达目标点时是否存在远离位置奇异点的候选姿态？
3. 从当前姿态到候选姿态的关节插值路径是否持续满足基础安全阈值？

> **重要边界**：本项目不是医疗器械控制器，也不能证明机械臂“不会伤人”。仿真仅覆盖几何、关节限位、底座/地面简化约束和位置雅可比奇异性。人体接触还必须验证动力学、结构强度、碰撞、自碰撞、力/扭矩限制、柔顺/阻抗控制、速度与加速度限制、通信失效、硬件急停、冗余制动和适用的医疗器械标准。

## 功能

- 四个互不重合的串联关节节点：J1–J2 可配置，J3 固定偏航，J4 固定俯仰
- 竖直直线轴 P1 可实时控制滑台高度，并进入系统位置雅可比
- 目标逆解可固定当前 P1 高度，或在完整升降行程内自动搜索安全高度
- 世界 Z 对齐的竖直末端连杆，以及其后新增的 L4 末端连杆
- 正运动学实时计算与零依赖 Canvas 三维投影
- 所有构型使用多初值阻尼最小二乘数值逆解
- 每个关节的电机正/反方向独立切换
- 界面内调整连杆长度、关节限位、治疗空间边界和基础安全阈值
- 3×5 位置雅可比、奇异值、条件数和可操作度计算
- 关节限位余量、底座禁入区、地面约束和治疗工作空间显示
- 当前姿态到目标姿态的离散关节路径检查
- 7×7×7 治疗空间网格扫描与 JSON 验证报告导出
- 无 CDN、无 npm 依赖、可完全离线运行

## 快速启动

### Jetson / Ubuntu

```bash
chmod +x start.sh
./start.sh
```

然后在 Jetson 本机或同一局域网的电脑打开：

```text
http://<Jetson-IP>:8080
```

只要求 Python 3.8+。端口可通过 `PORT=9000 ./start.sh` 修改。

### Windows

```powershell
.\start.ps1
```

### Docker（ARM64 可用）

```bash
docker build -t therapy-arm-sim .
docker run --rm -p 8080:8080 therapy-arm-sim
```

## 运动学模型

广义位置包含升降轴和四个旋转关节：`Q = [s, q1, q2, q3, q4]`。滑台绝对高度为 `h0+s`。J1/J2 的可配置轴在各自局部坐标系中定义；J3 轴与世界竖直方向以及 `Lv` 重合，J4 的俯仰轴随 J3 的偏航角旋转：

```text
Yaw   = local +Z = [0, 0, 1]
Pitch = local -Y = [0,-1, 0]
J3    = world +Z              # 竖直段顶端固定偏航
J4    = Rz(q3)·[0,-1,0]       # 竖直段底端固定俯仰
```

严格串联拓扑为：`P1 → J1 → L1 → J2 → L2 → J3 → Lv → J4 → L4 → TCP`。J1 位于滑台，J2 位于第一段白色连杆末端，J3 位于第二段白色连杆末端暨天蓝色竖直段顶端，J4 位于天蓝色竖直段底端。四个关节原点不再重合。令 `R(a,q)` 表示绕轴旋转，则位置关系为：

```text
R1 = R(a1,q1)
p_J2 = [0,0,h0+s] + R1[L1,0,0]
R2 = R1·R(a2,q2)
p_J3 = p_J2 + R2[L2,0,0]
R3 = R_world_Z(q3)
p_J4 = p_J3 + [0,0,d·Lv]
R4 = R3·R(local −Y,q4)
p_TCP = p_J4 + R4[L4,0,0]
d ∈ {-1,+1}  # 竖直末端向下/向上
```

默认尺寸：

| 参数 | 数值 |
|---|---:|
| 导轨基准高度 h0 | 0.18 m |
| 升降位置 s | 0.22 m（行程 0–0.50 m） |
| 上臂 L1 | 0.32 m |
| 前臂 L2 | 0.28 m |
| 竖直末端 Lv | 0.16 m（默认向下） |
| 新增末端 L4 | 0.12 m |

电机命令角与数学关节角的关系：

```text
q_model[i] = direction[i] × q_command[i]
direction[i] ∈ {-1, +1}
```

逆运动学使用多初值阻尼最小二乘（DLS）位置逆解，并按路径安全、终点安全、最小奇异值、限位余量、残差和总关节运动量综合排序。启用“自动搜索 P1”时，逆解还会在升降行程中搜索滑台高度，并对 P1 与四个转动关节的联合插值路径逐点检查。

### 轴组合不等于一定具有三维运动能力

J3/J4 分别固定为偏航/俯仰，因此界面只允许 J1–J2 的 4 种 Yaw/Pitch 组合。P1 提供独立 Z 向速度；系统是否满秩仍由完整 `3×5` 位置雅可比判断。

### 世界竖直末端的机械假设

`Lv` 在仿真中被约束为始终平行于世界 Z 轴，不随两段白色连杆倾斜。J3 位于它的顶端并绕 `Lv` 偏航，J4 位于它的底端并直接连接土黄色 `L4` 做俯仰。实物仍需要平行四边形、自调平机构或独立主动补偿维持 `Lv` 竖直；普通刚性串联连杆不会自动满足这一约束。

## 安全指标的含义

系统对包含 P1 的位置雅可比 `Jp (3×5)` 计算三个奇异值。由于直线轴单位为米、旋转轴单位为弧度，计算 SVD 前使用 `L1+L2+L4` 作为特征长度缩放 P1 列，避免条件数随单位选择而失真：

- `σmin < 0.025 m/rad`：视为接近位置奇异点。
- `condition number > 60`：视为运动放大风险过高。
- 任意关节距离限位不足 `4°`：视为安全余量不足。

阈值都在 `src/js/kinematics.js` 的 `DEFAULT_CONFIG.safety` 中。它们是可行性筛查参数，并非医疗安全标准。

### 一个无法绕开的事实

任何有限行程的串联机械臂，其完整几何工作空间边界通常都包含奇异姿态。因此“整个理论可达空间内任意一点都无奇异”并不现实。工程上应定义一个更小的 **安全工作空间**：其中每个点至少有一个满足关节余量、奇异性阈值和路径约束的姿态。本项目的治疗空间网格扫描正是用来估算这个集合，而不是把几何可达等同于安全可达。

## 如何改成你的机械臂

展开界面中的“机械参数与安全阈值”，即可调整：

- `links`：实际连杆长度（米）
- `linearAxis`：升降轴当前位置与上下行程
- `toolAssembly.verticalDirection`：世界竖直末端向上或向下
- `jointLimitsDeg`：实际机械限位（数学关节角，度）
- `jointAxes`：J1–J2 的 `yaw` / `pitch` 局部轴；J3 强制为世界 `yaw`，J4 强制为随 J3 旋转的 `pitch`
- `directions`：默认电机旋向
- `safety`：奇异值、条件数、限位余量、底座禁入半径和地面高度
- `therapyZone`：希望末端覆盖的长方体区域

点击“应用参数并重算工作空间”后，新参数立即用于正解、逆解、工作空间采样和覆盖扫描。界面刷新会恢复默认值；若希望固化为自己的机型，再把最终数值写入 `src/js/kinematics.js` 中的 `DEFAULT_CONFIG`。
