# Jetson 4DOF Therapy Arm Simulator

一个面向 **Jetson Orin Nano** 的、完全离线的 4 自由度连杆机械臂正逆运动学可行性验证仓库。它用于在制造样机前快速回答三个问题：

1. 给定连杆长度和关节限位，末端能否到达目标点？
2. 到达目标点时是否存在远离位置奇异点的候选姿态？
3. 从当前姿态到候选姿态的关节插值路径是否持续满足基础安全阈值？

> **重要边界**：本项目不是医疗器械控制器，也不能证明机械臂“不会伤人”。仿真仅覆盖几何、关节限位、底座/地面简化约束和位置雅可比奇异性。人体接触还必须验证动力学、结构强度、碰撞、自碰撞、力/扭矩限制、柔顺/阻抗控制、速度与加速度限制、通信失效、硬件急停、冗余制动和适用的医疗器械标准。

## 功能

- 四个关节均可独立选择局部 `Yaw` 或 `Pitch` 旋转轴
- 正运动学实时计算与零依赖 Canvas 三维投影
- 默认 Y-P-P-P 构型使用解析逆解，任意轴组合使用多初值阻尼最小二乘逆解
- 每个关节的电机正/反方向独立切换
- 界面内调整连杆长度、关节限位、治疗空间边界和基础安全阈值
- 3×4 位置雅可比、奇异值、条件数和可操作度计算
- 关节限位余量、底座禁入区、地面约束和治疗工作空间显示
- 当前姿态到目标姿态的离散关节路径检查
- 7×7×7 治疗空间网格扫描与 JSON 验证报告导出
- 无 CDN、无 npm 依赖、可完全离线运行

## 快速启动

### Jetson / Ubuntu

```bash
chmod +x start.sh
./start.sh
```

然后在 Jetson 本机或同一局域网的电脑打开：

```text
http://<Jetson-IP>:8080
```

只要求 Python 3.8+。端口可通过 `PORT=9000 ./start.sh` 修改。

### Windows

```powershell
.\start.ps1
```

### Docker（ARM64 可用）

```bash
docker build -t therapy-arm-sim .
docker run --rm -p 8080:8080 therapy-arm-sim
```

## 运动学模型

关节变量为 `q = [q1, q2, q3, q4]`。每个关节轴在该关节的**局部坐标系**中定义：

```text
Yaw   = local +Z = [0, 0, 1]
Pitch = local -Y = [0,-1, 0]
```

前级关节旋转后，后级关节的局部轴会随连杆姿态一起旋转。J1 和 J2 共用肩部原点；J2、J3、J4 旋转后分别沿局部 +X 方向连接 `L1`、`L2`、`L3`。默认轴组合为 `Yaw-Pitch-Pitch-Pitch`，此时闭式位置公式为：

```text
r = L1 cos(q2) + L2 cos(q2+q3) + L3 cos(q2+q3+q4)
x = r cos(q1)
y = r sin(q1)
z = h + L1 sin(q2) + L2 sin(q2+q3) + L3 sin(q2+q3+q4)
```

默认尺寸：

| 参数 | 数值 |
|---|---:|
| 底座高度 h | 0.18 m |
| 上臂 L1 | 0.32 m |
| 前臂 L2 | 0.28 m |
| 工具 L3 | 0.16 m |

电机命令角与数学关节角的关系：

```text
q_model[i] = direction[i] × q_command[i]
direction[i] ∈ {-1, +1}
```

默认 `Yaw-Pitch-Pitch-Pitch` 构型使用腕点解析法枚举冗余姿态。其他轴组合使用多初值阻尼最小二乘（DLS）位置逆解，并按路径安全、终点安全、最小奇异值、限位余量、残差和总关节运动量综合排序。

### 轴组合不等于一定具有三维运动能力

界面允许 16 种 Yaw/Pitch 组合，但并非每一种都能覆盖三维空间。例如四轴全为 Yaw 时，末端只能保持在固定高度的平面内运动；四轴全为 Pitch 时只能在一个竖直平面内运动。此时位置雅可比秩不足，界面会将其标记为奇异/不安全，而不会把数值上碰巧到达的点误报为安全三维构型。

## 安全指标的含义

系统对位置雅可比 `Jp (3×4)` 计算三个奇异值：

- `σmin < 0.025 m/rad`：视为接近位置奇异点。
- `condition number > 60`：视为运动放大风险过高。
- 任意关节距离限位不足 `4°`：视为安全余量不足。

阈值都在 `src/js/kinematics.js` 的 `DEFAULT_CONFIG.safety` 中。它们是可行性筛查参数，并非医疗安全标准。

### 一个无法绕开的事实

任何有限行程的串联机械臂，其完整几何工作空间边界通常都包含奇异姿态。因此“整个理论可达空间内任意一点都无奇异”并不现实。工程上应定义一个更小的 **安全工作空间**：其中每个点至少有一个满足关节余量、奇异性阈值和路径约束的姿态。本项目的治疗空间网格扫描正是用来估算这个集合，而不是把几何可达等同于安全可达。

## 如何改成你的机械臂

展开界面中的“机械参数与安全阈值”，即可调整：

- `links`：实际连杆长度（米）
- `jointLimitsDeg`：实际机械限位（数学关节角，度）
- `jointAxes`：四个关节各自的 `yaw` / `pitch` 局部旋转轴
- `directions`：默认电机旋向
- `safety`：奇异值、条件数、限位余量、底座禁入半径和地面高度
- `therapyZone`：希望末端覆盖的长方体区域

点击“应用参数并重算工作空间”后，新参数立即用于正解、逆解、工作空间采样和覆盖扫描。界面刷新会恢复默认值；若希望固化为自己的机型，再把最终数值写入 `src/js/kinematics.js` 中的 `DEFAULT_CONFIG`。
